⚙️ How to Start Every Time
Run these in order — takes about 10 seconds
1
✅ Setup (first time only — already done)
setup.bat
2
Start Ollama (AI model server)
ollama serve
In a separate terminal. Must stay running for AI answers.
3
Start FastAPI backend
start_server.bat
Runs on http://localhost:8000 — keep this terminal open.
4
Open frontend — VS Code Live Server
Right-click frontend/login.html → "Open with Live Server" (port 5500)
5
OR open this launcher file directly in browser
START HERE.html → double click to open in browser
