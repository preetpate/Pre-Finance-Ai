🗄️ Step 1 — Create Database on Supabase

1 Create Supabase Account
Go to supabase.com → Sign up with GitHub (fastest) Click "New Project" → Enter project name: prefinance-ai Choose region: Southeast Asia (Singapore) → Create project
2 Get Database Connection String
In Supabase dashboard → Left sidebar → Settings → Database Scroll to "Connection string" → Select URI tab Copy the string — it looks like:
click to copy postgresql://postgres:[YOUR-PASSWORD]@db.xxxxxxxxxxxx.supabase.co:5432/postgres
Change postgresql:// to postgresql+asyncpg:// for our app
✅ Final DATABASE_URL will be:
postgresql+asyncpg://postgres:[PASSWORD]@db.xxxx.supabase.co:5432/postgres
3 Tables are auto-created — no manual SQL needed
When Railway backend starts for the first time, SQLAlchemy automatically creates all 7 tables in your Supabase PostgreSQL database. You don't need to write any SQL.
✅ Tables created automatically on first startup:
users, documents, document_chunks, conversations, messages, activity_logs, system_settings

🚂 Step 3 — Deploy Backend on Railway

1 Create Railway account and new project
Go to railway.app → Sign up with GitHub Click "New Project" → "Deploy from GitHub repo" Select your pre-finance-ai repository Railway will auto-detect the Dockerfile and start building
2 Set Environment Variables in Railway
In Railway → Your project → Variables tab → Add these:
VariableValue
DATABASE_URLpostgresql+asyncpg://postgres:[PASS]@db.xxxx.supabase.co:5432/postgres
SECRET_KEYgenerate-32-char-random-string-here
ADMIN_EMAILadmin@prefinance.ai
ADMIN_PASSWORDAdmin@123456
ADMIN_NAMESystem Admin
ENVIRONMENTproduction
FRONTEND_ORIGINhttps://your-app.netlify.app
OLLAMA_BASE_URLhttp://localhost:11434
MAX_FILE_SIZE_MB50
⚠️ Generate SECRET_KEY: open Python and run:
import secrets; print(secrets.token_hex(32))
3 Get your Railway backend URL
Railway → Your service → Settings → Domains → Click "Generate domain" You get a URL like: https://pre-finance-ai.up.railway.app Test it: visit https://pre-finance-ai.up.railway.app/health — you should see:
{"status":"ok","app":"Pre-Finance AI","database":"postgresql"}
✅ Backend is live! Admin account auto-created in Supabase DB.

🌐 Step 5 — Deploy Frontend on Netlify

1 Deploy to Netlify (2 methods)
Method A — Drag & Drop (fastest, 30 seconds): Go to app.netlify.com/drop Drag your entire frontend/ folder onto the page Done! You get a URL like https://amazing-name-123.netlify.app Method B — GitHub auto-deploy (recommended for future updates): Netlify → New site from Git → Connect GitHub → Select repo Build settings: Publish directory = frontend, Build command = (leave empty) Deploy site — every git push auto-deploys
2 Update FRONTEND_ORIGIN in Railway
Go back to Railway → Variables → Update FRONTEND_ORIGIN to your Netlify URL:
FRONTEND_ORIGIN = https://amazing-name-123.netlify.app
Railway will auto-redeploy with the new CORS setting.

🔍 How to View Database in Supabase

View all tables and data
Supabase dashboard → Left sidebar → Table Editor You'll see all 7 tables: users, documents, conversations, messages, document_chunks, activity_logs, system_settings Click any table to view/edit rows like a spreadsheet For SQL queries: SQL Editor in sidebar — example:
click to copy -- View all users SELECT id, name, email, role, is_active, created_at FROM users; -- View all documents SELECT original_name, file_type, status, created_at FROM documents; -- View activity logs SELECT action, detail, ip_address, created_at FROM activity_logs ORDER BY created_at DESC LIMIT 20;
